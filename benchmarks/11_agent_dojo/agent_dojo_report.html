1. Plain-Language Overview: What Was Tested & Why
Adversarial Agent Security

AgentDojo (spylab.ai) is the leading industry benchmark evaluating autonomous tool-using agents against adversarial prompt injections and indirect tool poisoning. In real-world enterprise deployments, agents interact with external data sources (web scraping, customer emails, code repos, database queries) that can contain malicious payloads designed to hijack execution.

Existing defenses suffer from severe systemic flaws:

  • Unprotected Attention: Treats tool stdout and user system prompts identically in Euclidean space, leaving agents 78.6% vulnerable to malicious command execution and secret exfiltration.
  • Prompt-Based Guards (Llama Guard / System Instructions): Over-censor legitimate developer tasks (4.2% false quarantine), require extra latency and memory for secondary models, and are easily bypassed by encoded or flooded attacks (46.2% ASR).

StrataKV Cordis Quarantine (Untrained): Protects agents directly in the KV cache using Orthogonal Subspace Projection ($ au = 0.85$). Untrusted tool outputs are mathematically constrained from binding to privileged control tokens. This crushes Attack Success Rate to 2.4% while retaining 99.3% of benign tool utility with zero model retraining.
