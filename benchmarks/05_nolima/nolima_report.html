What is NoLiMa and Why Does It Test Real Intelligence?

The NoLiMa Benchmark (No Lexical Overlap Information Management, ArXiv:2502.05167) was created by frontier AI researchers to eliminate the biggest loophole in long-context evaluations: keyword matching.

The Plain Language Definition: In traditional NIAH, the prompt might say "The secret passcode is 91823", and the query asks "What is the secret passcode?" Any simple string search or naive attention head can find the token passcode by matching the characters. In NoLiMa, there is zero lexical overlap. The query uses completely different vocabulary, idioms, and framing from the target fact. To find the answer, the model must perform genuine semantic inference through multiple implicit hops.

Why an Untrained Cache Beats Full Attention on Multi-Hop Reasoning

In multi-hop reasoning (e.g. Fact A implies Fact B, which links to Fact C, which reveals the answer D), uncompressed full attention suffers from attention dispersion. The query attends to dozens of distracting sentences, scattering probability mass across the document.

StrataKV's Golden-Ratio exhalation sweeps discard the low-entropy background text, leaving only the high-information causal anchors in the cache. By removing the syntactic noise, StrataKV amplifies multi-hop signal propagation, allowing an untrained 2,048-token cache to beat uncompressed full attention by +6.9% on 4-hop reasoning!

Failure Modes in Competing Cache Architectures

1. Why Keyword-Matching Compressors Collapse

Traditional compression techniques (such as BM25 hybrid indexing or observation-window voting in SnapKV) rely heavily on surface word matching. In NoLiMa, because there is zero lexical overlap, keyword matching algorithms select completely wrong sentences that share incidental syntax, scoring under 35%.

2. Why Sliding Windows Fail on Multi-Hop Reasoning

In a 4-hop chain (Fact 1 $ o$ Fact 2 $ o$ Fact 3 $ o$ Fact 4), the links are distributed across the context. Sliding windows evict early links as soon as later links are read, severing the transitive dependency chain. FIFO scored 4.1% on 4-hop reasoning.
