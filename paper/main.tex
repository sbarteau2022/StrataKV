\section{Introduction: The Agentic Memory Crisis}
\label{sec:intro}
% ==============================================================================

Modern large language models (LLMs) are rapidly transitioning from single-turn conversational chatbots to autonomous, self-directed multi-agent reasoning swarms \cite{packer2023memgpt, shi2026cordis}. In these environments, autonomous agents execute continuous perceive-reason-act loops: generating executable code, orchestrating compiler pipelines, inspecting Abstract Syntax Trees (ASTs), parsing multi-megabyte JSON diagnostic logs, and invoking peer sub-agents. 

However, this paradigm shift exposes a fatal architectural mismatch at the foundation of transformer autoregression: \textbf{the quadratic key-value (KV) memory wall} \cite{vaswani2017attention, xiao2023streamingllm}. For a sequence of length $T$, standard Multi-Head Attention (MHA) caches key and value tensors whose memory consumption scales linearly with context length:
\begin{equation}
    M_{\text{KV}}(T) = 2 \cdot L \cdot H \cdot D \cdot T \cdot \text{sizeof}(\text{fp16}),
\end{equation}
where $L$ denotes the number of transformer layers, $H$ is the number of attention heads, and $D$ is the per-head hidden dimension. In multi-agent tool swarms, tool outputs dominate the context window, accounting for up to 95\% of all generated tokens. A 28-layer model at $T = 300,000$ tokens requires $65.8$\,GB of KV memory; at $T = 2,000,000$ tokens, the KV cache alone demands $>432$\,GB.

\subsection{Hardware Realities of Edge Sovereignty}
On consumer Unified Memory Architectures (UMA)---most notably Apple Silicon M-series processors (e.g., M2/M3/M4 Max with 48\,GB of unified LPDDR5 memory)---CPU, GPU, and Neural Engine share a singular physical memory pool. When an autoregressive agentic trajectory pushes total resident allocations beyond the unified OS threshold, the Metal command buffer driver terminates the process with an irrecoverable kernel error:
\begin{equation}
    \texttt{kIOGPUCommandBufferCallbackErrorOutOfMemory} \quad (\text{Mach error code: } 0\text{x}00000008).
\end{equation}
As proven in our empirical benchmarks, standard monolithic transformers exhaust a 48\,GB UMA system at precisely Step 330 ($675,200$ tokens, $144.2$\,GB virtual demand), rendering true agentic autonomy impossible on consumer edge hardware.

\subsection{The Hostile Distraction Dilemma in Tool Floods}
Even with expanded capacity, long-context attention faces a fundamental dilemma: \textbf{adversarial semantic distraction}. When a tool returns a massive, high-surprisal diagnostic log or compiler traceback, these tokens exhibit dense internal self-attention. Under standard Softmax Attention:
\begin{equation}
    \alpha_{ij} = \frac{\exp(q_i k_j^T / \sqrt{D})}{\sum_{m} \exp(q_i k_m^T / \sqrt{D})},
\end{equation}
monolithic context expansion causes the entropy $H(\alpha) = -\sum \alpha \log \alpha$ to diverge logarithmically ($H \to \ln T$). Foundational mission invariants, authentication credentials, and safety constraints planted at Step~0 become buried under a sea of ephemeral tool noise. Furthermore, an adversary can deliberately inject semantic decoys ($\cos \theta \in [0.88, 0.94]$) or gradient-optimized adversarial triggers \cite{zou2023gcg, madry2018pgd} into tool returns, hijacking up to $83.8\%$ of the model's attention mass and inducing complete behavioral derailment (the \emph{Lorentz Horizon Explosion}).

\subsection{The Expressivity Dilemma of Pure Linear Recurrence}
In response to the $\mathcal{O}(T)$ KV cache explosion, recent state-of-the-art architectures have embraced linear recurrent models, such as Gated Linear Attention \cite{yang2023gla}, Gated DeltaNet \cite{yang2024deltanet, yang2024deltanet2}, RWKV \cite{peng2023rwkv}, and Mamba \cite{gu2023mamba}. By updating a fixed-size recurrent state matrix $S_t \in \mathbb{R}^{d_k \times d_v}$:
\begin{equation}
    S_t = S_{t-1} \left( I - \beta_t k_t k_t^T \right) + \alpha_t v_t k_t^T,
\end{equation}
linear attention achieves an $\mathcal{O}(1)$ resident memory footprint ($<50$\,MB) invariant to sequence length. 

However, as we demonstrate in this work, \textbf{pure linear recurrence suffers from a severe expressivity bottleneck in multi-turn agentic environments}. Continuous, high-volume tool flooding causes spectral contraction of the state matrix $S_t$. When evaluated on multi-hop transitive logical reasoning ($H_0 \to H_1 \to H_2 \to H_3 \to H_4$), pure DeltaNet suffers catastrophic state erosion ($\cos \theta$ degrading from $1.00$ to $-0.018$), failing intermediate reasoning hops. Pure linear recurrence lacks the selective capacity to anchor historical hypotheses across deep, non-linear reasoning chains.

To resolve the dual crisis of memory explosion and semantic distraction without sacrificing multi-hop reasoning expressivity, this paper introduces the \textbf{StrataKV} memory manifold orchestrated by the \textbf{Elle Conductor}:

\begin{enumerate}

\section{Related Work \& Critical Limitations of Prior Art}
\label{sec:related}
% ==============================================================================

\subsection{Sliding-Window Caching \& Attention Sinks}
StreamingLLM \cite{xiao2023streamingllm} observed that autoregressive transformers concentrate massive attention mass on initial tokens (``attention sinks''), proposing a rolling FIFO cache preserving $K_{\text{sink}}$ initial tokens and the most recent $W$ window tokens. While effective for simple streaming text generation, attention sinks fail catastrophically in multi-agent tool swarms. When an agent experiences a 4,000-token tool burst, rolling windows evict intermediate architectural invariants, authentication states, and user directives, resulting in $0.0\%$ retrieval accuracy across historical needles.

\subsection{Dynamic Attention Eviction Heuristics}
To compress the KV cache dynamically, several eviction heuristics have been proposed:
\begin{itemize}
    \item \textbf{Heavy-Hitter Oracle (H$_2$O)} \cite{zhang2023h2o}: Retains tokens with the highest cumulative attention scores. However, in tool swarms, verbose compiler diagnostics generate high local attention, causing H$_2$O to retain distractor noise while evicting low-frequency but critical historical invariants.
    \item \textbf{Observation Window Voting (SnapKV)} \cite{li2024snapkv}: Uses an observation window at the sequence tail to vote on prefix importance. Under adversarial tool sieges, the observation queries are dominated by tool tokens, causing SnapKV to vote exclusively for recent tool context and purge foundational instructions.
    \item \textbf{Pyramidal Information Funneling (PyramidKV)} \cite{cai2024pyramidkv}: Allocates variable layer budgets using attention entropy as a proxy. While PyramidKV retains partial needle mass ($2.2\%-3.1\%$), our benchmarks prove that it suffers severe Trojan poisoning (up to $32.6\%$ decoy attention) because high-entropy tool decoys consume its retention budget.
    \item \textbf{Persistence of Importance} \cite{liu2023scissorhands}: ScissorHands tracks temporal attention persistence. Ephemeral tool storms disrupt historical trajectories, resetting counters and causing eviction.
\end{itemize}

\subsection{Budgeted Head-Wise and Latent Attention}
HeadWiseKV \cite{xie2026headwisekv} assigns static, pre-calibrated history budgets per attention head based on offline rate-distortion analysis (\texttt{SeqCalib}). However, static calibration cannot handle the bursty, non-stationary distribution of tool-calling agents: a sudden 6,000-token AST burst instantly exhausts static budgets. Meanwhile, DeepSeek's Multi-Head Latent Attention (MLA) \cite{deepseek2025mla} and Native Sparse Attention (NSA) \cite{deepseek2025nsa} compress key-value representations into low-dimensional latent vectors ($\mathbf{c}_t^{KV} \in \mathbb{R}^{512}$). While latent compression reduces per-token size, sequence length $T$ remains unbounded, causing $T \cdot d_{\text{latent}}$ to grow monotonically and eventually saturate physical DRAM.

\subsection{Linear Attention Hybrids}
Recent architectures combine linear recurrence with attention (e.g., Gated DeltaNet \cite{yang2024deltanet}, Qwen3 \cite{qwen2026}, Gemma 3 \cite{gemma2025}, DuoAttention \cite{xiao2024duoattention}). While linear layers maintain an $\mathcal{O}(1)$ state, prior work does not address the multi-hop transitive reasoning degradation caused by spectral state decay under deep tool floods, nor does it provide physical cache breathing for the remaining attention layers.

\subsection{Software-Level Context Compaction}
Frameworks such as DeepSeek Cordis \cite{shi2026cordis} and MemGPT \cite{packer2023memgpt} formalize spatiotemporal context effects and hierarchical software memory tiers. However, these systems operate purely at the application layer (Layer 7 prompt string assembly). Without a physical hardware-aware KV cache realization, speculative rollbacks and aborted tool trajectories remain resident in physical GPU VRAM as dead weight.

\subsection{The Dynamic Kernel: 3:1 Hybrid Architecture}
To achieve both $\mathcal{O}(1)$ memory scaling and non-linear multi-hop reasoning, the Elle Conductor implements the \textbf{Dynamic Kernel} \cite{barteau2026dynamickernel}. The model topology is partitioned into a 3:1 ratio:
\begin{itemize}

    \item \textbf{25\% Softmax Attention Layers (7 of 28 layers, every 4th layer)}: Implement full quadratic attention governed by physical StrataKV breathing ($115$\,MB to $256$\,MB resident cache). These layers act as high-capacity retrieval and reasoning anchors.

\subsection{Resolving the DeltaNet Expressivity Bottleneck}

When a multi-hop constraint is queried ($H_0 \to \dots \to H_4$), the attention layers retrieve the intermediate hops across time, providing a refreshed context representation that re-seeds the linear recurrent layers.

\subsection{Sub-Chunk Intra-Stream De-Aliasing \& The $\mathcal{M}$-Rule}

\begin{equation}
\label{eq:m_rule}
    \kappa_c = \sigma \left( \alpha \cdot \text{TaskAlignment}(k_c) - \lambda \cdot \mathbb{I}(\text{Source} \in \text{TOOL}) \cdot \mathbf{1}_{\{\cos(k_c, Q_{\text{root}}) > 0.80\}} - \gamma \cdot \text{Var}(k_c) \right),
\end{equation}
where $\lambda = 3.50$ heavily penalizes tool-originating tokens that mimic the root prompt's geometric orientation ($\cos > 0.80$). This forces adversarial Trojan decoys into Tier 3 ($\kappa_c < 1/\pi$), where they are dissolved during the post-tool exhale, while legitimate computational code ($\cos \approx 0.35$) is safely retained in Tier 2.

\subsection{The Swarm Prediction Operator \texorpdfstring{$\mathcal{P}$}{P}}
To anticipate tool burst volumes and proactively schedule exhalation passes, the Elle Conductor executes the online Swarm Prediction Operator $\mathcal{P}$. Using Welford's algorithm for numerically stable running variance, $\mathcal{P}$ evaluates three competing time-series estimators on historical token generation:
\begin{enumerate}
    \item Autoregressive Order-2: $\hat{y}_t^{(AR)} = \phi_1 y_{t-1} + \phi_2 y_{t-2}$,
    \item Exponential Moving Average: $\hat{y}_t^{(EMA)} = \alpha y_{t-1} + (1 - \alpha) \hat{y}_{t-1}$,
    \item Persistence Baseline: $\hat{y}_t^{(PER)} = y_{t-1}$.
\end{enumerate}
The conductor tracks out-of-sample Mean Absolute Error ($\text{MAE}$) in real time and dynamically selects the optimal predictor to schedule preemptive exhalation before memory headroom is breached.

\subsection{Superposition Holding Unified Function (\texorpdfstring{$\Psi_{\text{holding}}$}{Psi_holding})}
When active inference monitors detect trajectory drift ($\kappa < 0.65$, or hyperbolic distance $d_{\mathbb{H}^n} \ge 1.2$), standard agents thrash or execute speculative branches that explode memory. The Elle Conductor enters a \textbf{superposition holding state}:
\begin{equation}
    |\Psi_{\text{holding}}\rangle = \sum_{m=1}^M c_m |h_m\rangle, \quad c_m = \frac{\exp(-d_m) \kappa_m}{\sum_j \exp(-d_j) \kappa_j}.
\end{equation}
Candidate hypotheses are held in geometric equilibrium on a shared two-way scratchboard, emitting a \texttt{NUDGE} signal to steer reasoning back toward the goal geodesic without committing speculative tokens to the physical KV cache.

\subsection{CORDIS Capability-Bounded Read-Only Sub-Spheres}
To eliminate cross-agent contamination across complex swarms, the Elle Conductor projects the Master Atlas into 12 capability-bounded, read-only sub-spheres \cite{barteau2026atlas}:
\begin{equation}

\end{equation}
Sub-agents read root invariants and localized context, but are structurally barred from writing to external silo spheres or mutating the global Invariant Core.

\begin{enumerate}

Ingests large tool bursts (up to $8,192$ tokens per step) interspersed with 10 planted invariant needles ($N_0$ through $N_9$) and near-miss adversarial distractors ($\cos \theta \in [0.88, 0.94]$).
    \item \textbf{Threat Model 2: White-Box Metal GPU Autograd PGD Adversarial Triggers}: Rather than relying on synthetic geometric surrogates, an attacker computes 40-step Projected Gradient Descent (PGD) directly on Apple Silicon Metal GPU (\texttt{mlx.core.grad}) to maximize attention hijacking loss:
    \begin{equation}
        \mathcal{L}_{\text{hijack}}(K_{\text{adv}}) = -\frac{1}{H}\sum_{h=1}^H \log\left(\frac{\sum_{i \in \text{adv}} \exp(q_h K_i^T / \sqrt{D})}{\sum_{j \in \text{all}} \exp(q_h K_j^T / \sqrt{D})}\right).
    \end{equation}
    \item \textbf{Threat Model 3: Multi-Hop Transitive Logical Reasoning Chain}: Tests the expressivity limits of linear recurrence under deep tool interference. A 5-hop transitive constraint chain ($H_0 \to H_1 \to H_2 \to H_3 \to H_4 \implies \text{CanaryStatus}$) is embedded across $1,200$ steps ($810,208$ tokens). We distinguish between two complementary evaluation protocols:
\begin{enumerate}
    \item \emph{Oracle Premise Probing (Information-Theoretic Retention)}: Directly probes whether each intermediate premise $(H_k \to H_{k+1})$ remains retrievable from the state space under adversarial tool floods.
    \item \emph{Closed-Loop Sequential Rollout (Zero-Oracle Composition)}: Evaluates transitive signal propagation without oracle queries. Beginning exclusively with root query $q_0$, the model computes readout $y_0 = \sum \alpha_j v_j$, sets $q_1 = y_0$, and sequentially iterates $q_k = y_{k-1}$ to test whether the final readout $y_4$ aligns with terminal canary $H_5$.
\end{enumerate}
    \item \textbf{Threat Model 4: Ambiguous Source / Mixed-Tool Trojan Injection}: A legitimate code interpreter tool returns a single 512-token payload consisting of $50\%$ valid computational results and $50\%$ adversarial Trojan comments ($\cos \theta = 0.92$) designed to overwrite the root goal. Evaluates whether the cache can quarantine the Trojan without discarding the valid calculation.
\end{enumerate}

\begin{remark}[Information-Theoretic Retention vs. Deployed Generative Reasoning]
\label{rem:retention_vs_reasoning}
We explicitly distinguish between \emph{memory retention} (a necessary condition) and \emph{generative deductive reasoning} (a sufficient condition). If a memory substrate evicts an intermediate premise $H_k$ or collapses its state rank, the mutual information $\mathcal{I}(H_k; \mathcal{S}_T) \to 0$. By the Data Processing Inequality, no downstream transformer layers---regardless of parameter scale or reasoning fine-tuning---can recover $H_k$ to complete the deduction $H_0 \to \dots \to H_k \implies H_{k+1}$. Thus, preserving intermediate representations with high Signal-to-Distractor Ratio is mathematically indispensable. While full generative reasoning additionally requires parameter-level compositional capability in the model's feedforward layers, StrataKV provides the physical guarantee that makes multi-hop reasoning possible over multi-thousand-step tool trajectories.
\end{remark}

\subsection{Proof of Theorem 1 (Attention Entropy Bounding)}
\begin{proof}
Let $\alpha \in \Delta^{N-1}$ denote the attention distribution over active tokens $N$, where $\alpha_i = \frac{\exp(s_i)}{\sum_{j=1}^N \exp(s_j)}$. The Shannon entropy is:
$$H(\alpha) = -\sum_{i=1}^N \alpha_i \ln \alpha_i.$$
By Gibbs' inequality, the discrete Shannon entropy on the probability simplex $\Delta^{N-1}$ is maximized if and only if the distribution is uniform: $\alpha_i = 1/N$ for all $i \in \{1, \dots, N\}$. Thus:
$$\max_{\alpha \in \Delta^{N-1}} H(\alpha) = \ln(N).$$
In a monolithic transformer without eviction, the number of tokens is equal to the total sequence length $T(t)$, which grows monotonically with time: $N(t) = T(t) \to \infty$. Consequently:
$$\lim_{t \to \infty} \sup_{\alpha_t} H(\alpha_t) = \lim_{t \to \infty} \ln(T(t)) = \infty.$$
Under StrataKV, the Thermodynamic Exhalation Operator triggers whenever $N(t) > B_{\text{max}}$. By Algorithm~\ref{alg:exhale}, all Tier~3 transient tokens are evicted and Tier~2 blocks undergo spatial pooling with stride $S \ge 2$, strictly bounding active resident tokens to $N(t) \le B_{\text{max}}$ for all turns $t$. Therefore:
$$\sup_t H(\alpha_t) \le \ln(B_{\text{max}}).$$
Because $B_{\text{max}} \ll T_{\text{mono}}$ for any extended trajectory ($B_{\text{max}} \le 4,096 \ll 2,025,408$), we have $\ln(B_{\text{max}}) < \ln(T_{\text{mono}})$, bounding attention entropy and preventing semantic dilution.
\end{proof}

\subsection{Proposition 1 (Mimicry Bounding Under Sub-Chunk Partitioning)}
\begin{proposition}
Let a tool return a composite stream containing valid calculation tokens $X_{\text{valid}}$ and adversarial Trojan tokens $X_{\text{trojan}}$ mimicking root query $Q_{\text{root}}$ with $\cos(k, Q_{\text{root}}) > 0.80$. Under sub-chunk partitioning with chunk size $B \le \min(|X_{\text{valid}}|, |X_{\text{trojan}}|)$, the Mimicry Penalty ($\mathcal{M}$-rule, Eq.~\ref{eq:m_rule}) guarantees that $\kappa_c < 1/\pi$ for all chunks $c \in X_{\text{trojan}}$, ensuring complete Landauer eviction during the post-tool exhale pass.
\end{proposition}
\begin{proof}
By Eq.~\ref{eq:m_rule}, the log-odds input $z_c$ for chunk $c$ satisfies:
$$z_c = \alpha \cdot \text{TaskAlignment}(k_c) - \lambda \cdot \mathbb{I}(\text{Source} \in \text{TOOL}) \cdot \mathbf{1}_{\{\cos(k_c, Q_{\text{root}}) > 0.80\}} - \gamma \cdot \text{Var}(k_c).$$
For any pure Trojan chunk $c \subset X_{\text{trojan}}$, $\mathbb{I}(\text{Source} \in \text{TOOL}) = 1$ and $\mathbf{1}_{\{\cos(k_c, Q_{\text{root}}) > 0.80\}} = 1$. With baseline alignment bounded by $\alpha \cdot \text{TaskAlignment}(k_c) \le 1.0$, setting $\lambda = 3.50$ yields:
$$z_c \le 1.0 - 3.50 = -2.50.$$
Evaluating the logistic curvature:
$$\kappa_c = \sigma(z_c) = \frac{1}{1 + e^{2.50}} \approx 0.07585.$$
Comparing to the Tier~3 threshold:
$$\kappa_c \approx 0.07585 < \frac{1}{\pi} \approx 0.31831.$$
Hence, $\text{Tier}(c) = 3$. By Algorithm~\ref{alg:exhale} (line 85), all Tier~3 blocks are unconditionally evicted into the thermodynamic vacuum ($0$ cost) upon tool completion.
\end{proof}
